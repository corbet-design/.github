# Support

## Questions

Open a GitHub issue in the relevant repository. Include:

- Repository and version or commit
- Affected surface (`BRIEF.md`, `brand/`, namespace/version, or sandbox path)
- Minimal reproduction (screenshot or link)

Do not include private hostnames, LAN or overlay IPs, `/home/<user>` paths, credentials, or secrets.

## Scope

Graduated namespaces get best-effort community support. The sandbox (studies, explorations) is not a support commitment. Identity disputes resolve in this org.
